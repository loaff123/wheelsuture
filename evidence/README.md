# Public qualification evidence

These archives preserve the bounded qualification described in [QUALIFICATION.md](../docs/QUALIFICATION.md). They are historical run receipts, not claims that all environments or arbitrary wheels are supported. Every archive is public in this repository; no private download is needed.

- [Installer oracle](qualified-rc2-evidence.zip): 17 pip scenarios, 39 original boundaries, 11 actionful repairs with 26 actions, five already-satisfied replicas and one conflict; nine independent PyPA mapping layouts and 44 claims. Includes original fixtures, frozen runtime/harness source, per-boundary observations, command receipts and notices
- [Capacity](capacity-evidence.zip): 37 constrained recipes and measured resource outcomes. Thirteen expected-limit tracebacks have their original project-root prefix replaced by `<PROJECT>`. Numeric measurements, outcomes and source/harness digests are unchanged; receipt and manifest hashes are rebound
- [Installed packages](package-evidence.zip): wheel/Python 3.12.14, sdist-rebuilt wheel/Python 3.12.14 and wheel/Python 3.13.5 each passed all 198 tests. Includes the unchanged tested direct/rebuilt wheels, deterministic-output hashes, runtime audit, command logs and artifact-content receipts
- [Package summary](PACKAGE-VERIFICATION.json) records the original qualified artifact hashes. The original source-distribution archive is intentionally omitted from the public copy because its historical documentation included development-workflow text; its original hash and contents receipt remain. Build a current source distribution from this checkout instead. Do not mistake current documentation for byte-identical historical artifact documentation
- [Publication-corrected packages](publication-package-evidence.zip): the corrected checkout was built again and passed all three installed phases, 198 tests each. Includes the new direct wheel, rebuilt wheel and source distribution, all 67 deterministic outputs, and 390 hash-bound receipts. [Current artifact summary](PUBLICATION-PACKAGE-VERIFICATION.json) records their new hashes. The original artifact evidence above remains a separate historical run
- [Publication changes](PUBLICATION-CHANGES.json) records each evidence-copy change and original archive digest

The oracle archive contains the official hash-pinned PyPA installer 0.7.0 wheel, its MIT license and provenance. Its upstream platform launchers are retained byte-for-byte but are never executed by these Linux mapping tests. No disposable environments or private credentials are distributed. The installed WheelSuture package does not bundle third-party implementations.

Archive paths reflect the original evidence layout. Extract into a separate empty directory for inspection. `qualification/ARCHIVE-SHA256.json` binds the oracle archive; `qualification/evidence/qualified-rc2/evidence-sha256.json` binds the frozen run; `package-qualified-001/evidence-sha256.json` binds retained package evidence; `capacity/manifest.json` binds capacity receipts. `capacity/summary.json` binds that manifest. [REPRODUCING.md](../qualification/REPRODUCING.md) describes fresh runs and required tooling.

The source documents were corrected for publication after the original package gate, then rechecked in the publication-corrected installed-package gate. All runtime modules, schemas, example plans and fixture wheels remain identical to the qualified candidate. Library CI is a separate four-interpreter test/build gate; it does not qualify additional installer profiles.
